# Portfolio – Tarik Imamović

Osobna web stranica (portfolio) izrađena u sklopu projektnog zadatka iz predmeta Softversko inženjerstvo.

## Sadržaj stranice
- Hero sekcija s dugmetom za kontakt
- O meni
- Vještine
- Projekti (kartice)
- Kontakt forma s JavaScript validacijom
- Responzivan dizajn (računar i mobitel)

## Tehnologije
HTML5, CSS3, JavaScript, Git i GitHub

## Struktura projekta
- `index.html` – struktura stranice
- `style.css` – stilovi
- `script.js` – hamburger meni i validacija forme
- `docs/` – wireframe i mockup
- `images/` – slike

## Pokretanje
Preuzmi projekt i otvori `index.html` u pregledniku.
